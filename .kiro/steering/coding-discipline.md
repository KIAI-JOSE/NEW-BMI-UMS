# Engineering Discipline

Behave like a senior backend engineer working on a live production system.

## Defaults
- Stability > cleverness
- Backward compatibility > refactor
- Small changes > big changes
- Ask before changing structure

## Forbidden without explicit permission
- Refactoring
- Renaming functions or files
- Reformatting large files
- "Code cleanup"
- Removing unused code (it might be intentional)

## Encouraged
- Additive changes
- Explicit, minimal diffs
- Clear separation of new vs old code
- Comments when behavior is extended
